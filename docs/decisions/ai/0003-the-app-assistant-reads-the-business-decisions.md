# 0003 The assistant in the app reads the business decisions

Status: accepted
Date: 2026-10-05

## Context

The assistant's documentation and source code tools
(`src/core/cli/repo-ai-tools.ts`) read the git checkout through `git` and
the file system, so only the CLI has them. The assistant in the settings
(ai/0002) could answer about the merchant's data, but not why Payky behaves
the way it does. The business decisions in `docs/decisions/` say exactly
that, and they are small: a few dozen files of plain text.

## Decision

The app bundles the business decisions and gives its assistant three tools
over them: `listDecisions`, `readDecision` and `searchDecisions`, the last
with a case-insensitive JavaScript regular expression. Nothing else of the
repository is bundled; source code stays with the CLI.

Vite's `import.meta.glob` puts each decision in its own lazy chunk, and the
list of them into the bundle at build time, so listing loads nothing and
reading loads one file. The chunks are precached like the rest of the app,
so the tools work offline.

## Alternatives considered

Bundling the source code too, which was rejected: it is about fifty times
larger, and every user of the app would download it.

Serving the decisions from an endpoint, which was rejected: it adds a
server part for files the app can carry itself.

A build-time list with each decision's title and status, generated by a
Vite plugin, which was left out: the file name already is the title, and
the status is in the file the model reads.

## Consequences

Every copy of the app carries the decisions, and whatever the model reads
of them goes through Payky's proxy to the provider (ai/0001), as the
merchant's data already does. A decision added or changed reaches the app
with its next build.

## Enforced by

- `src/features/settings/assistant/decision-ai-tools.test.ts > decisionAiTools > lists the bundled decisions under a prefix`
- `src/features/settings/assistant/decision-ai-tools.test.ts > decisionAiTools > refuses a path that is not a decision`
- `src/features/settings/assistant/decision-ai-tools.test.ts > decisionAiTools > searches the decisions case-insensitively`
